# Code of conduct

Emberfin follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and constructive, assume good intent, and keep discussion about the work.
Harassment, insults, personal or political attacks, and publishing anyone's private information
(including their server address or library) are not tolerated in issues, pull requests or any other
project space.

## Enforcement

Report unacceptable behaviour privately to the maintainer: use GitHub's **Report content** option on
the comment, or the private **Report a vulnerability** form under the Security tab. Reports are
handled confidentially. The maintainer may edit or remove comments and block contributors who break
these rules, following the Contributor Covenant's enforcement guidelines.
